# 账户私有资产（A03）

此模块替代旧版“只存浏览器”的顾客数据策略。账号私有空间保存照片、人体测量、任务记录及 GLB；IndexedDB 是可恢复缓存。异步下载在账号切换后停止保存，防止串号。

## 访问与存储

- `/api/account/storage` 返回当前账号清单、用量、配额和保留期；记录、文件、写入和删除均校验 JWT。存在且属于其他账号的标识返回 403。
- 上传和生成的照片、GLB 自动归档；完成的建模、试穿、精修任务由工作线程保存。浏览器确认接收仅释放临时工作区，不删除归档。重启后可恢复私有资料、图片和模型。
- 文件经鉴权下载后以 Blob URL 预览，无公共静态路径或长期下载链接。账号接口 `no-store`，公共部署沿用 HTTPS 代理，API 仅监听回环地址。
- `data/private/index.sqlite3` 保存归属、随机对象键、尺寸、时间及加密记录；`data/private/objects/<随机键>` 保存 Fernet 认证加密文件。目录 0700、文件 0600，测量、照片、历史和原文件名不明文持久化。
- 密钥单独位于数据目录同级 `<数据目录名>.keys/customer-assets.key`，不在资产树或仓库。首次自动创建；已有数据库而密钥丢失时启动失败。这个位置是有意的——备份 `data/` 不会把解密它的钥匙一起带走——但也意味着 `data/` 的忽略规则覆盖不到它，所以 `.gitignore` 用 `*.keys/` 单独排除，换一个 `DATA_DIR` 名字同样有效。

## 上传与生命周期

- 按内容验证 PNG/JPEG/WebP，10 MiB 输入、2500 万像素、禁止动态图像；重编码去除 EXIF，面部照片短边 512 像素。GLB 最大 150 MiB 并校验容器；有效几何由建模结算另行校验。
- 每条 JSON 最多 256 KiB，每账号最多 2000 条记录，默认逻辑空间 500 MiB。写事务保护并发配额与替换。应用和 Nginx 限制请求大小。
- `ITP_PRIVATE_ASSET_QUOTA_MB` 可调配额，`ITP_PRIVATE_ASSET_RETENTION_DAYS` 默认 365 天。每小时清理超期记录和孤儿对象；删除与替换移除旧文件。
- 账户页提供确认迁移、恢复、重试及确认删除。同步失败保留缓存并显示失败；旧记录仅在确认后迁移，匿名及其他账号分区不自动认领。
- 删除全部数据同时停止当前账号任务、退还未成功结算的建模积分并清除当前设备缓存。其他设备缓存需各自清除。旧共享资产及测量目录不自动认领或删除。

## 备份与恢复

项目根目录运行 `python scripts/private_assets.py cleanup` 可立即清理；`python scripts/private_assets.py backup --destination <受限备份目录>` 在写锁下复制一致的数据库与加密对象，不包含密钥、临时工作区或旧共享数据。密钥须备份到另一个受限位置；恢复时分别恢复数据库/对象及密钥，再启动服务。

运维将备份保存至独立受限介质，最多保留 7 天，到期清除。用户删除后活动副本立即移除，既有备份在保留期结束清除，不用于日常读取。密钥和备份分别授权、分别存放。

## 验收

`tests/test_private_assets.py` 覆盖重启、加密、权限、跨账号、内容/元数据/配额、并发拒绝、过期、孤儿清理、缺失密钥、旧数据保护及 GLB 归档。Playwright 桌面/手机覆盖第二设备恢复、删除确认、同步失败保留缓存及确认迁移。
