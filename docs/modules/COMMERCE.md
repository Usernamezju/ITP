# 钱包、会员与周期额度

资金及权益复用 `merchants.sqlite3`，没有另建账号库。客户端通过
`/api/pricing` 读取价格、通过 `/api/account/commerce` 查看自己的余额、
订阅和额度，通过 `/api/account/ledger` 分页读取自己的资金流水。
顾客/商家均不填写 API Key。钱包没有客户端直接增加余额的接口。

## 资金与建模

- 金额全部为整数分，Python 校验拒绝浮点、布尔和负价格，SQLite 再以
  `typeof(...)='integer'` 和余额非负约束兜底。前端解析商品价格使用十进制
  字符串拆分，不用浮点乘法后四舍五入。
- `wallets` 是余额快照，`wallet_ledger` 是追加流水。同一账户、类型和交易
  reference 唯一；同一次充值/退款不会重复入账，不同金额的重复请求拒绝。
- 建模默认 1500 分/次，年会员默认 3000 分/12 个日历月。由服务端
  `ITP_MODEL_PRICE_CENTS`、`ITP_CUSTOMER_MEMBERSHIP_PRICE_CENTS` 配置。
- 创建建模任务与试穿继续建模均要求登录和 `Idempotency-Key`（8–128 字符）。
  `BEGIN IMMEDIATE` 下扣款和预留任务编号；幂等键按账号隔离，同一键不同
  请求返回 409。流水仅保留业务编号、金额、时间、不可逆请求摘要，不记录
  照片路径、模型路径或人体指标。钱包不足返回 402，不产生流水或任务。
- 任务入队失败、云端失败、没有有效结果、拒绝姿势审核自动退款。
  只有成功且产物具有合法 GLB 网格结构或 OBJ 顶点/面才保留扣费；仅有
  `glTF` 魔数或截断文件不算有效结果。局部产物可保留展示，但失败任务退款。
- 启动时恢复漏结算和入队前崩溃的扣费；已有进行中任务不重复云提交。
  姿势审核超过任务期限自动拒绝并退款。临时工作区的取消/清理与浏览器
  本地化已在 C04 完成（见 [顾客本地数据与临时计算](PRIVACY.md)）；
  本模块不声称旧持久资产已删除。
- 充值与会员购买的官方验签和订单履约属于 C03；本模块没有用前端
  “支付成功”标记代替验证。

## 通用权益模型

`commerce_plans` 配置名称、目标身份、价格、日历月周期、布尔/整数权益、
启用和可购买状态。`subscriptions` 保存订单对应的已购买权益快照以及起止
时间；调整套餐不追溯修改已购买权益。同套餐续费从已有到期时间顺延。
重叠套餐同一上传权益取最高额度，不静默叠加；续费的未来权益尚未生效。

免费商家默认每 **1 个日历月 5 次上传**。以注册时间为周期锚点，UTC
月末自动截断，闰年正确处理（1 月 31 日 → 2 月 29 日 → 3 月 31 日）。
每次新建商品与 `usage_buckets.used + 1` 在同一 SQLite 写事务提交，多个
连接/进程竞争不能超额。SKU 重复不消耗次数。删除商品、转为草稿不会
恢复已消耗次数；编辑与补商品图不算新的商品上传。

`ITP_MERCHANT_FREE_UPLOAD_LIMIT` 与 `ITP_MERCHANT_FREE_PERIOD_MONTHS` 修改
免费政策；旧 `ITP_MERCHANT_QUOTA` 只兼容历史字段，不再控制永久商品数。
`ITP_COMMERCIAL_PLANS` 是 JSON 数组，可添加任意价格、周期和商业层级。
本项目不擅自设置未确定的商业会员价格。

旧数据升级为加表迁移，不删原账号和商品。首次迁移将当前周期内仍存在的
商品上传记录计入使用量一次；旧系统没有记录已删除商品的历史，无法追溯
还原这些过去次数。迁移后所有上传消耗独立留存，不再依赖现存商品数量。

## 验证与发布边界

单元测试覆盖分值类型、余额不足、并发扣费、重复退款、崩溃恢复、月末
周期、并发上传、删除不恢复、套餐快照、续费及到期。Playwright 使用非默认
服务端价格验证页面，保证不是前端硬编码金额。

本阶段公网仍保留旧共享工作台 Basic gate。账号及建模任务使用 JWT，建模
列表和读取按 owner 隔离；未绑定身份的历史任务不自动分配给新注册账户。
顾客图片/试穿/测量结果的权限与临时存储边界已在 C04 完成切换，未处理的
旧持久记录仍未迁移；在清理存量并撤下 gate 之前，不能把当前版本当作
完全开放的多租户商业站点。
