# Web 工作台

前端位于 `frontend/`，使用 React、TypeScript、Vite、Three.js。构建资源打包到 `frontend/dist/` 后由 FastAPI 本地提供；运行时不依赖境外 CDN。开发服务器使用 Vite 的本地 `/api` 代理。默认服务仅绑定回环地址。

## 页面与交互

工作台左侧上传角色、姿势、多视角并选择生成步骤；中间显示 GLB 预览与每阶段产物；右侧显示服务配置状态与任务历史。打开资产时，预览标题旁显示该任务的目标面数、姿势模式、拓扑、纹理、绑骨、FBX 导出选项和调用模型。新任务保存创建时的模型版本；旧任务若没有记录版本，页面会明确显示“版本未记录”。左侧导航的设置页可填写腾讯云和千问服务地址、模型与凭据，保存后立即生效。历史页从本地 SQLite 读取任务，不调用外部系统。已上传图片显示预览，去背景开关仅影响后续上传。

左侧导航的「穿搭推荐」与人体建模、虚拟试穿并列，用于把三维模型的比例转成成套穿搭。左侧选择分析来源（默认取最近一个含 GLB 产物的任务，可切换其它任务或选择不使用模型），并按风格、季节、场合筛选；中间上半区显示模型实测的轮廓切片与肩宽、腰线、胯宽、腿身比指标，下半区是按匹配度排序的套装卡片，每张卡显示该套的检索图片与配色；点开卡片可浏览更多参考图并查看套装单品、穿着建议、不适合的情况与本次推荐理由，每张图都保留来源与原图链接；右侧列出可用于分析的模型、图片检索服务状态与本地服务状态。图片按单品与风格从检索服务获取并缓存在本机，取不到图片时自动回落到配色示意图。尚无三维模型时按通用体型推荐，并在页面上给出前往人体建模的入口。

「人体建模」页的生成设置里还有一组**选填**的人体数据（身高、体重、肩宽、胸围、腰围、臀围），保存后按任务归档。它们是「穿搭推荐」做尺码匹配的输入：填了身高才能把模型比例换算成厘米，未填项由模型比例推算并在界面上标为「估算」（腰围/臀围由正视图宽度按椭圆周长换算，误差较大，会附警告；胸围模型没有对应比例，只能实测）。推荐结果因此可以逐维度展示「你的数值 / 该款适配区间 / 合身状态 / 中文理由」。

商家侧通过接口导入商品（见 [商家接口](MERCHANT.md)），导入后该套在推荐页会标记「商家」，卡片直接使用商家上传的商品图而不是网络检索图；已发布套装优先于单件，二者都没有时才回落到内置目录。

左侧导航的「商家后台」是给商家上货用的页面，与浏览侧的几个页面并列：未登录时显示注册/登录卡片，登录后顶部显示商家名、账号、联系方式与配额用量（含进度条）以及「账号设置」入口，下面在「我的商品」与「我的套装」之间切换。商品列表逐条给出颜色块或商品图、品类、价格、图片数量和适配区间摘要，可直接编辑、发布、转为草稿或删除；新建与编辑表单分成「基本信息」「尺寸与适配区间」「版型与属性 + 商品图」三段，下拉项、取值范围与长度上限全部来自 `GET /api/garment-options`，越界或区间倒置会就地提示且不发出请求；套装页从已发布的单品里勾选组合，配色默认取成员主色，可先存草稿。登录令牌保存在浏览器本地，刷新不掉线，令牌失效时自动回到登录页。「账号设置」里可以改密码（需要当前密码），改完会立刻退出登录——因为改密即吊销旧令牌，需要拿新密码重新登录一次；忘记密码只能在本机用 `scripts/reset_merchant_password.py` 重置。

点击“开始生成”会列出尚缺的角色图、姿势参考图、服务配置或绑骨确认项。已上传图片可点击放大，另有更换与移除按钮。设置页提供森林绿、海洋蓝、暖日橙、暮光紫、科技风、少女粉配色和标准、高对比度选项；外观选择只保存在浏览器本地。常见云端错误码显示中文排查建议，同时保留原错误码与 RequestId。

如果未配置云端 API，上传、预处理和本地 GLB 导入可用，生成按钮显示“生成服务待配置”。姿势编辑阶段结束后，用户须确认或放弃姿势图。未确认前，3D 阶段不会启动。

Three.js 预览只接受自包含 GLB。导入用户文件或服务返回的 GLB 后自动居中、归一化尺寸，支持旋转、缩放、线框视图。OBJ、FBX、ZIP 均提供真实文件下载，当前预览器不解析这些格式；附加外部纹理引用、Draco 等压缩扩展也未实现。

前端每 3 秒查询任务列表，页面关闭后停止定时器。较大模型载入、WebGL 不可用和格式错误会给出提示；模型场景与 GPU 资源在组件卸载时释放。空白场景中的线框立方体仅为视觉指示，不表示生成了模型。

## 构建与测试

前端锁文件 `package-lock.json` 固定安装版本，`npm ci` 用于复现；`npm run build` 会先进行 TypeScript 检查。Playwright 在桌面和手机视口覆盖未配置状态、图片上传、姿势模式切换、本地 GLB 导入、任务历史和配置面板。真实任务审核与产物下载仍需云端账号联调。

密钥由后端写入并读取本地 `.env`，网页在保存时发送输入的密钥，不保存到浏览器存储，也不读取已保存的密钥。工作台是本机单用户应用；外网部署需要认证、配额、隔离和新的跨域策略。
