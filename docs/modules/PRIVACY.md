# 顾客本地数据与临时计算

## 存储契约

长期服务端存储仅允许账号、资金、订单、权益和商户主动发布/保存的商品资料。
顾客照片、姿势图、六视图、GLB、人体指标及任务历史属于浏览器 IndexedDB，
按账号 ID 分区，未登录素材使用匿名分区。更换设备不会自动同步个人模型；
清理站点数据会删除本机数据，用户应下载重要结果。

`frontend/src/localData.ts` 提供事务式 Blob/结构化数据保存和启动恢复。
Blob URL 只在当前页面内有效，重新打开时从 IndexedDB 创建，不保存过期 URL。
本地保存失败应明确显示存储权限/空间错误，不能声称已保存，也不能确认服务端
已交付。浏览器分区是 UI 隔离，不替代服务端 JWT 权限或操作系统账号安全。

`src/itp/transient.py` 提供可复用临时 Store：SQLite 元数据只在 RAM 中，
输入及工作文件仅在标记的临时目录存在。任务结束删除工作文件，输出仅以
有限容量和短 TTL 的 RAM 交付缓冲等待浏览器事务保存并确认；断连也由 janitor
过期删除。取消后禁止迟到的模型响应重建临时文件。重启只清理本服务标记的
临时目录，不删除其他数据目录、模型权重或备份。资金持久记录不含照片路径。

## 迁移与当前状态

本模块分基础设施及调用链切换两步提交。基础设施阶段不改变既有部署数据
访问方式；只有完整切换资产/任务/推荐接口、浏览器调用及权限测试后，才能
移除共享工作台 gate。具体完成状态见 `docs/PLAN.md`。

服务端调用链已切换：`POST /api/assets`、`/api/face-photos`、`/api/model-assets`
直接写入 RAM 元数据并绑定账号；任务、试穿与脸部精修在结束时删除工作文件，
只把结果留在 RAM 交付缓冲，浏览器调用 `/api/jobs/{id}/acknowledge`、
`/api/tryons/{id}/acknowledge`、`/api/face-refinements/{id}/acknowledge` 后连同
任务记录一起删除。`POST /api/outfits/recommend` 接受浏览器当次上传的 GLB 与
人体指标，计算完成后立即删除模型，不读取服务端 `body_profiles`。商户商品图
继续写入独立持久目录 `data/commercial`。`/api/body-profile` 接口暂时保留以
兼容旧页面，待浏览器接线完成后随 gate 一并处理。

旧 `studio.sqlite3`、试穿/精修数据库、`body_profiles` 和备份不能无授权清空，
也不能自动归属第一个注册用户。切换时应停止网页读取旧共享记录，并只迁移
商户商品图。旧顾客记录的受保护导出/删除由拥有者确认后处理，未处理的
受保护历史备份必须如实披露，不可声称已经全部销毁。
